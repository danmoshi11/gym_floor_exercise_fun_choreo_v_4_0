GymChoreo 版本迭代日志

Floor Exercise Choreography System

Version 3.2.0 当前版本
云端生态与安全校验模块
  • 接入 Supabase 数据库，实现全球成套排行与勋章冲榜系统
  • 设计端对端完整性校验，限制只有内置名将且未篡改的成套数据允许上传
  • 构建 CoinManager 经济系统，引入每日签到获取金币与打榜门票扣费机制
Version 3.1.0
多媒体打点与三维演示引擎
  • 集成 Three.js 与 GLTFLoader，完成 2D 场地平面坐标向 3D 舞台的矩阵换算
  • 建立动作编排与骨骼动画映射字典，支持常规着陆和摔倒姿态回放演示
  • 接入 WaveSurfer.js，支持成套音乐波形渲染、本地异步加载与快捷键打点卡位
Version 3.0.0
半自动裁判系统与状态机管理器
  • 重构 RulesEngine，支持根据 FIG 动作库特征精准过滤动作局部的 E裁扣分与 D裁降组
  • 引入 HTML5 拖拽事件并添加 GhostNode 内存保护，构建抽屉式人工交互打分面板
  • 编写全局编排审查逻辑，实现开场跟翻、收尾无舞蹈、技巧串超标的自动侦测警告
  • 设计 FlowStateManager，支持 7 种核心功能状态锁及历史版本的 Undo/Redo 控制堆栈
Version 2.0.0
跨文件跨进程协作与数据压缩
  • 新增 WorkspaceManager，支持多达 5 张独立草稿纸一键切换、深拷贝隔离与静默暂存
  • 设计 ShareEngine，通过轨迹关键点抽样编码，实现无损的 6 位短码成套口令导出与还原
  • 集成 html2canvas 开发长图导出工具，支持一键保存包含全量判罚细节的结算成绩小票
Version 1.0.0
图形渲染与核心规则校验
  • 开发基于 HTML5 Canvas 的高保真自由体操场地轨迹绘制、曲线平滑与拖拽选点系统
  • 搭建基础 FIG 算分中枢，实现 A-J 组动作难度分（D分）与连接加分（CV）自动累加校验
  • 编写数据预加载管理层与 Python 脚本，支持 FIG 国际名将头像与国旗 Emoji 异步动态解析
